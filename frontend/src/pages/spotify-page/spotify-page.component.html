Connect Spotify

You will be sent to Spotify to approve the link. YEPPDash asks for playback control and nothing else — no library, no playlists, no listening history. It stays linked afterwards, so chat can request tracks while you are streaming without you being on this page.

Controlling playback needs Spotify Premium. Spotify no longer says up front whether an account has it, so a free account links successfully and then refuses the first command.

Chat commands

The bot reaches the same queue this page does, so anything here can be done from chat.

!spotify
What is playing right now
!spotify queue
The next few tracks
!spotify <link>
Adds a track by link, URI or id
!spotify <search>
Adds the best match for a search
!spotify skip
Skips the current track
!spotify play / pause
Starts and stops playback

shield Anyone can look and request; only you and your moderators can skip, play or pause.
