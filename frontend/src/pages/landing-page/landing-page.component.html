construction Heads up: this is beta software

YEPPBot has existed as a beta project for a long time, but its integration with this dashboard, as well as every feature currently running, is still very much work in progress.

This dashboard itself only launched at the end of July 2026, so it's still in an early beta phase. The current UI and design will change significantly, more features will be added, and some existing ones will change too.

Both the bot and the dashboard run stably, but there's no guarantee of permanent uptime, and data loss can happen. Most features run largely without issues, though bugs may already exist.

Found one? Feel free to open an issue. Got a change suggestion or a feature request? Open an issue or contribute yourself. This project is and always will be open source: no ads, no annoying platform lock-in.
