Chat commands

The bot drives the same timer this page does, so anything here can be done from chat instead.

!timer start
Starts it counting down
!timer stop
Holds it where it is
!timer add 5m
Puts time on
!timer remove 5m
Takes time off, never below zero
!timer set 8h
Replaces whatever is left, paused
!timer reset
Back to the start value above, paused

shield Only you and your moderators can use these — chat cannot touch the timer.
